# Contributing to SWRFUSS

Thanks for helping out! We love code, but we love fun even more.

## Commit Messages

- Please make your commit messages funny, witty, or packed with Star Wars/MUD references.
- Examples:
  - "Refactored code—now with less Ewok confusion"
  - "Fixed a bug—Han shot first"
  - "Gave pointers the Force so they stop going to the dark side"
- Boring messages will be sent to the Sarlacc pit.

## Coding Style

- Use modern C++23 and x64 conventions. See copilot-instructions.md for details.

## Pull Requests

- Open a PR, describe your change, and make sure tests pass.
- If you change commands, update `/area/help.are`!

## Questions?

Open an issue or ask in Discord!
